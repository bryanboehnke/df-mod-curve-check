Models for X_0(N) together with equations of maps X_0(N) \to E over Q were found using code of Jacob Mayle and Jeremy Rouse, available at (https://github.com/rouseja/ModCrvToEC).

Code for showing that X_0(N) has no translates of E in W_7^1 over F_p for (N,p) = (82, 3), (99, 2), and (128, 3) was adapted from code of Maarten Derickx, available at (https://github.com/nt-lib/density-degree-5-X0/tree/main).
